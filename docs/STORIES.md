# UnbloatMyMac stories

The backlog. Each story has checkable acceptance criteria. The Thimble project
"UnbloatMyMac Roadmap" mirrors the open ones; this file is the source.

## Done (0.1.0 code)

- [x] **S-001 Tweak engine with exact undo.** Every change saves the value from before in `journal.json`; undo restores it. *Check:* `EngineTests` "restores the value from before", "journal survives a relaunch".
- [x] **S-002 Apple Intelligence off, feature by feature.** Writing Tools, Genmoji, Image Playground, Image Wand, ChatGPT, summaries, inline predictions, Siri, and the AI background services. *Check:* profile flow test.
- [x] **S-003 Privacy, Performance, Annoyances, Finder, Dock, Typing tweaks.** 88 tweaks at first, no two write the same key. *Check:* `noSharedKeys` test.
- [x] **S-004 Windows Mode.** Scroll direction, F-keys, Home/End, maximize, snap, scroll bars, taskbar Dock, drives on desktop, plus a full preset.
- [x] **S-005 Review before apply.** Changes are staged, listed in a sheet with what happens (password, profile, restarts, log out), then applied. One password prompt for all admin changes. *Check:* `onePrompt` test, review snapshot.
- [x] **S-006 Presets.** Recommended, Maximum Privacy, Performance Boost, Windows Mode. *Check:* self-test "a preset stages only what is not applied".
- [x] **S-007 Background Items.** Stop and allow third-party launch agents and daemons.
- [x] **S-008 Storage cleanup.** Caches, logs, Xcode data, simulators, installers, device updates, local snapshots; files go to the Trash.
- [x] **S-009 History and Undo Everything.** *Check:* `undoEverything` test, self-test.

## 0.1.0 — first public release

- [ ] **S-010 Check every tweak on a real Mac (macOS 27).** Apply and undo each category on a real Mac; each switch shows the right state after Refresh, and undo leaves `defaults read` as before. *Owner.*
- [ ] **S-011 Check the Apple Intelligence profile on macOS 27.** The profile installs from System Settings, the features disappear, removing it brings them back. Note any restriction key macOS ignores. *Owner.*
- [ ] **S-012 Check the password prompt and cancel.** One prompt for several admin tweaks; Cancel reports "You canceled" and changes nothing. *Owner.*
- [x] **S-013 Full Disk Access guidance.** When a protected setting fails, the result offers a button that opens Privacy & Security > Full Disk Access. *Check:* self-test reaches the button on the pretend Mac.
- [x] **S-014 App icon.** A Liquid Glass icon made with Icon Composer, reviewed in light, dark, and tinted looks.
- [x] **S-015 README, license, and screenshots.** README explains what changes, how undo works, and the risks.
- [x] **S-016 CI.** GitHub Actions runs the unit tests on every push.
- [x] **S-017 Release script.** `tools/release.sh <version>` signs with Developer ID and the hardened runtime, notarizes, staples, zips, and prints the command that publishes the GitHub release.
- [x] **S-018 Notary credentials.** `xcrun notarytool store-credentials UnbloatMyMac` with an app-specific password, so the release script can notarize. *Owner.*
- [x] **S-019 Publish 0.1.0.** Repo public on GitHub, release with the notarized zip, downloads open without a Gatekeeper warning. *Owner.* Waits on S-010.

- [x] **S-039 Recommended apps with Homebrew.** A Recommended Apps page lists free apps and tools by group (Windows habits, command line, Mac utilities, privacy), installs one or all recommended with Homebrew, and shows how to get Homebrew when it is missing. *Check:* self-test "Install Recommended installs every starred app", `AppsTests`.
- [x] **S-040 Shell setup for terminal tools.** Oh My Posh, eza, zoxide, and fzf can add one line each to `~/.zshrc` in a marked block; turning one off or uninstalling removes only its line. *Check:* `AppsTests` "Adding and removing shell lines leaves the rest of ~/.zshrc as it was".
- [x] **S-041 Apps from the command line.** `unbloatmymac apps | install <app>… | install --recommended | uninstall <app>…`. *Check:* `tools/test-cli.sh`.
- [x] **S-042 Vorssaint as the all-in-one pick.** On Apple silicon, Vorssaint is recommended instead of AltTab, Rectangle, Maccy, LinearMouse, Stats, MonitorControl, and AppCleaner, which say "Vorssaint does this too". - [x] **S-043 Local AI apps.** A Local AI group lists offline AI apps and tools: Ollama, LM Studio, oMLX, Osaurus, Jan, AnythingLLM, Draw Things, ComfyUI, DiffusionBee, VoiceInk, MacWhisper, llama.cpp, MLX LM, whisper.cpp. None is starred, so Install Recommended never downloads them; Apple silicon only apps are hidden on Intel. *Check:* `AppsTests` "Local AI apps are listed".
- [x] **S-044 App updaters.** An App Updates group lists macCurrent (starred), Updatest, Latest, Applite, topgrade, and mas. macCurrent is not in Homebrew, so its row says Download and opens maccurrent.com, and Install Recommended and `install --recommended` skip it. *Check:* `AppsTests` "App updaters are listed".
- [x] **S-045 Cleaners.** A Cleaners group lists Mole (starred), AppCleaner, Pearcleaner, OnyX, GrandPerspective, OmniDiskSweeper, Czkawka, and dust. AppCleaner and Pearcleaner say "Vorssaint does this too" on Apple silicon. *Check:* `AppsTests` "Cleaners are listed".
- [x] **S-046 Activity Log.** A Tools page lists everything the app and the command line tool did to the Mac: each defaults write with its exact command, each service, profile, command, file, background item, cleanup, and app install. Level chips (Debug, Info, Warning, Error) with counts, a source menu, search, an inspector with the full command, Copy, Export Log…, Clear Log…. Lines are in English, kept in `activity.log` next to the journal, newest 5,000. *Check:* `ActivityLogTests`, self-test "the activity log lists both tweaks", "a refused setting is an error in the activity log", "Clear Log empties the activity log".
- [x] **S-047 Help.** Help > UnbloatMyMac Help (⌘?) opens a window with task-based topics (getting started, tweaks, review, Apple Intelligence, undo, background items, storage, apps, activity log, command line, settings, troubleshooting, shortcuts), in English and French. - [x] **S-051 Back up and restore settings.** File > Back Up Settings… (⇧⌘B) and Restore Settings… (⇧⌘R), also in Settings > General > Backup, save one file with the tweaks that are on and the app's own settings (advanced tweaks, restarting apps, accent, language, update checks). - [x] **S-052 Update settings.** Settings > Updates turns automatic update checks on or off, shows the version and when it last checked, and has Check Now. - [x] **S-053 Install progress.** Installing or updating several apps shows "Installing 3 of 8: Mole…" with a progress bar in the Recommended Apps header, in place of the installed count. *Check:* `apps-progress-light.png` and `apps-progress-dark.png` snapshots, self-test "Update All updates it".
- [x] **S-054 Update installed apps.** Rows of apps Homebrew installed show Update when Homebrew has a newer version, and the header offers Update N Apps. - [x] **S-055 Backup and app updates from the command line.** `unbloatmymac backup <file>` and `restore <file>` save and restore the app's settings with the applied tweaks (one confirmation; `--dry-run` lists each setting and tweak). `outdated` and `update <app>… | --all` update apps Homebrew installed. The app picks up restored settings when you switch back to it. *Check:* `tools/test-cli.sh`.
- [x] **S-056 Notice put-back tweaks at login.** Settings > General > Notifications > "Tell me when macOS puts back tweaks" registers a login agent (SMAppService, `Contents/Library/LaunchAgents`). At each login it runs `UnbloatMyMac --login-check`, which posts one notification per set of put-back tweaks, even when the app is closed. If macOS asks, the setting links to Login Items. *Check:* `EngineTests` "The login check tells once about tweaks a macOS update put back", self-test "the login notification counts the put-back tweaks". *Owner:* turn it on and check the notification after the next macOS update.
- [x] **S-057 What a tweak changes.** An ⓘ button next to each tweak opens a popover with the exact commands it runs (`defaults write …`, `launchctl disable …`, profile restrictions, files, key bindings), how undo puts each back, its id, and Copy Commands. *Check:* `EngineTests` "Every tweak can say what it runs and how undo puts it back", `details-light.png` and `details-dark.png` snapshots.
- [x] **S-058 Security page.** A Security category turns on the firewall and stealth mode, and turns off Remote Login, Remote Apple Events, the guest user, and wake for network access, plus AirDrop for contacts only. Sharing switches show the feature, like System Settings. All of them share one password prompt, and undo puts back each one. A Status section reports FileVault, Gatekeeper, System Integrity Protection, security responses, and automatic login, with Open Settings when one needs attention; the app never changes those. Maximum Privacy adds the firewall, stealth mode, Remote Apple Events, and AirDrop. *Check:* `SecurityAndStorageTests`, self-test "turning on the firewall and off Remote Login stages both", `security-light.png` and `security-dark.png`. *Owner:* apply and undo each one on a real Mac.
- [x] **S-059 Developer and web app caches.** Storage has three sections (Apps and System, Developer Files, Privacy Traces) and adds Web App Caches (Cache, Code Cache, GPUCache folders of Chromium and Electron apps in Application Support, found by their markers), Saved Window States, Simulator Caches, and Package Manager Caches (npm, Bun, pnpm, Cargo, Go, Gradle). *Check:* `SecurityAndStorageTests` "Web app caches are found only in Chromium app folders, and settings stay".
- [x] **S-060 Privacy traces.** Storage clears the download history (the LaunchServices quarantine events database) and the Recent Items lists. Favorites in the Finder sidebar stay. *Check:* `SecurityAndStorageTests` "Storage targets have unique ids, and each group has some".
- [x] **S-061 Leftovers from deleted apps.** Storage > Leftovers from Deleted Apps > Review… (Changes > Review Leftovers from Deleted Apps…, ⌥⌘L) lists items in Application Support, Preferences, Saved Application State, HTTPStorages, and WebKit named after a bundle id that no installed or registered app has, and that nothing changed in 30 days. Apple's are never listed; items from a developer with another installed app start unchecked. Checked items move to the Trash, only from those folders. Containers are left out, since measuring them makes macOS ask for access to other apps' data. *Check:* `SecurityAndStorageTests` leftover tests, self-test "moving leftovers to the Trash removes them from the list", `leftovers-light.png` and `leftovers-dark.png`.
- [x] **S-062 Browser telemetry and Handoff.** Privacy turns off Chrome usage reports, Edge diagnostic data, and Firefox telemetry through each browser's policy keys (each says the browser may show it is managed), and Handoff. *Check:* `SecurityAndStorageTests` "Browser telemetry tweaks write each browser's own policy keys".
- [x] **S-063 Leave a change out in Review.** Each row in Review Changes is a menu: the change (picked by default) or Leave On / Leave Off. Left-out changes stay listed until Apply, the Apply button counts only the chosen ones, What Happens lists only theirs, and applying drops the rest from the staged changes. Useful when another app, like Vorssaint, already manages a setting. *Check:* self-test "Leave in Review keeps that setting and applies the rest", `review-light.png` and `review-dark.png`.
- [x] **S-064 Switches read the right way round.** Every tweak's description says what happens with its switch on: feature switches (Share Mac Analytics, Autocorrect, Game Center…) describe the feature, like System Settings, instead of what turning it off does. A **Recommended: On / Off** tag shows where the switch should be for every preset tweak and every Apple Intelligence, privacy, and security tweak that stops no system service; it is in the accent color while the switch is on the other side. Typing, Windows Mode, and other matters of taste have no tag. *Check:* `EngineTests` "Every description says what happens with the switch on" and "Recommended switches point at the unbloated side", `privacy-*.png` and `typing-*.png` snapshots.
- [x] **S-065 Clean without fighting open apps.** Found in the Activity Log on a real Mac: App Caches failed every time on caches macOS protects, and leftovers listed Sparkle's helper, Python, Playwright, and a temporary cookie file. Now App Caches leaves Apple's protected caches (com.apple.*, CloudKit, familycircled) alone, and Clean… names the open apps that use the files (matched by bundle id, name, bundle name, or executable): **Quit and Clean** asks them to quit first, **Clean the Rest** leaves their files. Failures name the items. Leftovers skip shared frameworks and tools (Sparkle, Python, WebKit, Electron, Chromium, Keystone, Microsoft AutoUpdate) and temporary files. *Check:* `SecurityAndStorageTests` "Cache folders are matched to open apps…", "Shared frameworks, tools, and temporary files are never leftovers", "Quit and Clean asks the open apps to quit, then cleans", self-test "Quit and Clean quits them and cleans everything".
