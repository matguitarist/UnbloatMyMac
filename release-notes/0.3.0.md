## The same Help menu as every app

- **What's New in UnbloatMyMac** opens the latest release notes.
- **Report a Problem…** opens a new GitHub issue with the app version, build and macOS version already filled in.
- **Check for Updates…** is always in the UnbloatMyMac menu, greyed out when updates aren't available.
- Every page is in the View menu; the first ten open with ⌘1–⌘0.
- **Show Log** (⌘L) replaces Show Activity Log.
